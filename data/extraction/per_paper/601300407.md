## Evidence writeup

**Design.** Retrospective multicenter cohort (5 Hainan hospitals, 2019-2021, n=942) predicting severe outcomes after hymenopteran stings → `Observational`, `N_Participants=0`.

**XAI.** SHAP, `Both` scope (global mean-|SHAP| feature ranking + local force plots for 3 representative cases).

**Evaluation.** `ProxyMetric` — SHAP feature importance plus bootstrap stability check (CV<15% across 100 resamples), no human judgment of the explanation.

**Realism/EV.** `Realism_Level=1`, all EV floor at 0. Borderline: a deployed web calculator exists (Fig. 9) but only author-run illustrative examples, no evaluated user session → `EV_Environment=0`, not 1.

**Quality/RoB.** `QR_Participant=0` (clinical-decision-improvement claims with zero clinician evaluation, matching the rubric's own boundary example); `QR_Faithfulness=2` for the bootstrap stability metric, though it measures cross-retrained-model stability rather than single-model fidelity — an imperfect match to the rubric's intent. `QR_Reporting=1` — SHAP explainer variant/config never specified.

**Method Justification.** `Mixed` — cognitive (comprehension/validation) + workflow (clinical adoption, regulatory compliance) grounds, no comparison to alternative XAI methods.

**Framework Classification.** `DoshiVelez_Category=FunctionallyGrounded`, `VilonLongo_Category=Objective` — both mechanical, agree.

**Reg_*.** All `No` — "low model confidence" caveat is a stated limitation/recommendation, not a tested or implemented uncertainty-surfacing feature.

1. **`Zotero_Key`** — blank.
2. **Domain doesn't cleanly fit the controlled vocabulary** — this is Emergency Medicine/Toxicology, not Radiology/EHR/Pathology/ICU/Pharmacy/Oncology/Cardiology. Coded `EHR` as closest residual category. Given this review is ED-focused, worth considering whether the schema needs an explicit `EmergencyMedicine` domain value — check if this recurs on paper 7 before deciding.
3. **`EV_Environment=0` vs. 1** — a web calculator exists but wasn't evaluated with any user, only author-run demos. Borderline; could argue 1 if you weight the tool's existence over its lack of evaluated use.
4. **`Clinician_Design=No`** — authors are ED-affiliated and clinical accessibility shaped feature selection, but no explicit co-design process is described. Borderline, same pattern as `Xie_2021`.
5. **`QR_Faithfulness=2`** — stability-across-bootstrap-models is a genuine but imperfect stand-in for single-model fidelity; flag if you want a stricter read.
6. **`Trust_Claim=Plausibility`** — thin trust language (one sentence plus a citation to other literature); reviewer may prefer `None` under a stricter bar.
